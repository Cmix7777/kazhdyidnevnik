# Мгновенные уведомления о сообщениях

Переписка в Каждыйдневнике работает и без этого: пока приложение открыто, сообщения приходят за пару секунд, а когда закрыто, телефон проверяет новые примерно раз в 15 минут. Чтобы уведомление приходило сразу, нужен посредник, который будит второй телефон через Firebase. Свой сервер для этого не нужен: хватает бесплатного скрипта Google Apps Script на твоём Google-аккаунте. Настраивается один раз, минут за десять, денег и карты не нужно.

Сообщения при этом остаются зашифрованными: скрипт и Google видят только набор знаков, ключ есть лишь у двух телефонов.

## 1. Номер приложения в Firebase

1. Открой [console.firebase.google.com](https://console.firebase.google.com) и проект **kazhdyidnevnik**.
2. Шестерёнка слева вверху → **Настройки проекта** (Project settings) → вкладка **Общие** (General).
3. Внизу, в «Ваши приложения» (Your apps), нажми **Добавить приложение** → значок Android.
4. Имя пакета: `io.github.cmix7777.kazhdyidnevnik`, остальное пусто → **Зарегистрировать приложение**. Шаги со скачиванием файла и SDK пропусти кнопками «Далее» и «Перейти в консоль».
5. В карточке приложения скопируй **App ID**, он выглядит как `1:1234567890:android:abc123def456`.

## 2. Ключ сервисного аккаунта

1. Там же, в настройках проекта, вкладка **Сервисные аккаунты** (Service accounts).
2. **Создать закрытый ключ** (Generate new private key) → **Создать**. Скачается файл `.json`.
3. Этот файл — пароль к пушам проекта: никому не пересылай и не выкладывай. Он нужен только для следующего шага.

## 3. Скрипт

1. Открой [script.google.com](https://script.google.com) тем же Google-аккаунтом → **Новый проект**. Назови его, например, «Каждыйдневник пуши».
2. Сотри всё в `Code.gs` и вставь содержимое файла [`Code.gs`](Code.gs) из этой папки. Сохрани (значок дискеты).
3. Слева шестерёнка **Настройки проекта** → внизу **Свойства скрипта** → **Добавить свойство скрипта**, два раза:
   `APP_ID` — App ID из первого шага;
   `SERVICE_ACCOUNT` — всё содержимое скачанного `.json` (открой его Блокнотом, Ctrl+A, Ctrl+C).
   Нажми **Сохранить свойства скрипта**.
4. Вернись в **Редактор** (значок `< >` слева), вверху выбери функцию `check` и нажми **Выполнить**. Google попросит разрешение: «Проверить разрешения» → свой аккаунт → «Дополнительные настройки» → «Перейти к проекту» → «Разрешить». В журнале внизу должно появиться «Всё готово». Если там ошибка, она по-русски подскажет, что не так.
5. Справа вверху **Начать развёртывание** → **Новое развёртывание** → шестерёнка «Выберите тип» → **Веб-приложение**. Запуск от имени: **Я**. Доступ: **Все**. → **Начать развёртывание**.
6. Скопируй **URL веб-приложения**: он заканчивается на `/exec`.

## 4. Телефон

1. Отправь ссылку себе на телефон (например, в Telegram) и скопируй её там.
2. Каждыйдневник → Настройки → **Сообщения** → **Вставить ссылку**. Должно появиться «Готово».
3. На втором телефоне ничего делать не нужно: он получит ссылку сам вместе с перепиской.

На Redmi (HyperOS) пуши до закрытого приложения доходят, только если ему разрешён автозапуск: Настройки → Приложения → Каждыйдневник → **Автозапуск** включить, а в «Контроль активности» выбрать **Нет ограничений**. На Samsung обычно ничего не нужно; если уведомления опаздывают, в настройках батареи приложения выбери «Без ограничений».

## Если поменял скрипт

После правки `Code.gs` нужно «Начать развёртывание» → «Управление развёртываниями» → карандаш → Версия «Новая версия» → «Развернуть». Ссылка при этом остаётся прежней.

## Сколько это стоит

Ничего. У Apps Script бесплатно 20 000 запросов наружу в сутки, у Firebase пуши бесплатны без ограничений, а на одно сообщение уходит один запрос.
