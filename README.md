# Каждыйдневник

Личное Android-приложение на двоих: расписание пар, смены, план учёбы, прогресс и дедлайны.
Слева страница Айзата (группа ДИС-234/21Б, МВЕК), справа — Насти (торговое дело, колледж УдГУ), между ними свайп.

## Что внутри

- Kotlin + Jetpack Compose (Material 3), тёмная и светлая тема (переключатель в настройках, можно «как в системе»): у Айзата фиолетовая, у Насти сиреневая с небесно-голубым
- Одно приложение на двух телефонах: при первом запуске оно спрашивает, чей это телефон; свои уведомления приходят владельцу, про второго человека — по желанию
- Шрифт Manrope (SIL Open Font License 1.1, текст лицензии в `licenses/Manrope-OFL.txt`)
- Расписание Айзата берётся с открытого сайта timeo.mveu.ru, Насти — из таблицы Excel на сайте колледжа (f-mkpo.udsu.ru); .xls и .xlsx читаются без сторонних библиотек
- Свои дела (работа, вождение, учёба и другое): разовые или каждую неделю, с напоминанием заранее; можно и через полночь, например с 23:00 до 02:00
- Дорога: до колледжа выходят раньше, до работы позже (у Айзата 40 и 10 минут, у Насти 50 и 18)
- Дела второго человека: телефоны связываются один раз кодом (Настройки → Связь), дальше дела обмениваются сами через бесплатное облако Firebase (Firestore, тариф Spark, без аккаунтов и карты): при открытии приложения и примерно раз в 3 часа. Хранится только расписание дел и смен, без заметок, бюджета и дат; документ открывается только по длинному случайному коду связи. Передать дела сообщением вручную тоже можно
- Бюджет: доходы и траты с категориями, остаток по дням на графике, статистика за месяц
- Важные даты можно добавлять и менять прямо в приложении
- Данные, дела, бюджет и прогресс хранятся на телефоне (в облако уходит только то, чем делишься со вторым телефоном)
- Фоновая проверка расписания (23:00, 6:30 и примерно раз в 3 часа) и уведомление, если пары изменились
- Напоминания: утренняя сводка, начало блоков учёбы, вечерняя отметка сделанного
- Погода в Ижевске (open-meteo.com): сейчас и по часам, погода при выходе и на обратном пути с советом, что надеть, предупреждения (гололёд, сильный ветер, снегопад), прогноз на неделю и уведомление о погоде на завтра
- Обновление прямо из приложения: оно само находит новую версию в Releases
- Автокопия прогресса раз в день в «Загрузки/Каждыйдневник» и восстановление из файла
- Сборка, тесты и выпуск версий — GitHub Actions

## Как установить

1. Открыть на телефоне раздел [Releases](../../releases) этого репозитория.
2. Скачать `kazhdyidnevnik.apk` из последней версии.
3. Открыть файл и разрешить установку.

Дальше обновления ставятся из самого приложения: «Настройки» → «Обновления».

## Как идёт разработка

Каждый пуш в `main` запускает тесты и сборку. Если ключ подписи задан в секретах репозитория, автоматически выходит новая версия в Releases.

Секреты репозитория (Settings → Secrets and variables → Actions):

- `SIGNING_KEYSTORE` — ключ подписи в base64
- `SIGNING_PASSWORD` — пароль ключа

Ключ подписи хранится только у владельца. Без него нельзя выпускать обновления, которые встанут поверх установленной версии.

## Облако (Firebase)

Проект Firebase `kazhdyidnevnik` (Firestore в Европе, тариф Spark, анонимный вход). Приложение ходит в него по REST, без библиотек Google (`data/CloudShare.kt`).
Правила базы разрешают читать и писать только документы `shares/<код>-<имя>` длиной имени 20–60 знаков с двумя полями (`payload`, `updatedAt`); список документов и удаление закрыты:

```
rules_version = '2';
service cloud.firestore {
  match /databases/{database}/documents {
    match /shares/{shareId} {
      allow get: if request.auth != null && shareId.size() >= 20 && shareId.size() <= 60;
      allow create, update: if request.auth != null && shareId.size() >= 20 && shareId.size() <= 60
        && request.resource.data.keys().hasAll(['payload', 'updatedAt'])
        && request.resource.data.keys().hasOnly(['payload', 'updatedAt'])
        && request.resource.data.payload is string && request.resource.data.payload.size() < 300000;
      allow list, delete: if false;
    }
  }
}
```
